# Generation 2 licensing strategy — NOT an EULA

**Status:** proposed product policy; not a legally finalized license.

## Current direction
The Generation 2 native server is planned as **proprietary, source-closed software**, distributed as binaries free of charge under an EULA that still needs approval. Third-party add-ons may be supported through an explicitly documented and separately licensed SDK.

**This public planning repository does not grant a general license to reproduce, modify, redistribute or sublicense proprietary Gen2 server code.** It contains architecture descriptions, not the native server source.

## Distinguish Gen1 from Gen2
OpenGenesisLINK Generation 1 originates from OpenSimulator and includes source governed by MPL-2.0 and other applicable licenses. Its license is not automatically the license of an independently authored Generation 2 server. Copied or modified Gen1/OpenSimulator code **retains its applicable obligations** and must not be inserted into a closed Gen2 distribution without legal compatibility review.

## Before any binary/SDK release
1. Approve the EULA, distribution permissions, rights holder and trademark notices.
2. Audit every third-party source package, asset, dependency and protocol implementation.
3. Document SDK/add-on licensing, redistribution, API stability and plugin sandbox policies.
4. Publish the applicable notices, source offers where required, warranty terms and privacy terms.
5. Define the policy for external contributions and IP rights.

No publication of software or binary distribution is authorized by this planning document alone.
