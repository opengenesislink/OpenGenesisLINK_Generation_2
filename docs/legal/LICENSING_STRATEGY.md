# Licensing strategy — decision record, NOT a final EULA

## Decision
OGL Gen2 server is intended to be **free of charge to run**, including commercial grid operation, while the official server implementation remains proprietary and source-closed. Official binary releases and SDK add-ons are envisaged. The Global Atlas directory is intended to be free to register/use, subject to fair-use and anti-abuse terms.

## Important legal distinction
No LICENSE file granting software permissions is included yet. This document is not a binding grant or an operative EULA. "Free to use" will become enforceable only when rights holders publish approved terms. All rights reserved until then.

## Proposed EULA scope
Grant to run official binaries; commercial grid operation; installation/update/backup rights; redistribution rules; restrictions on modified core distribution subject to mandatory law; third-party add-on creation via supported SDK; operator/user ownership of independently created content; service terms for Atlas; privacy, security, termination, warranties, liability and applicable law.

## Open-source and third-party obligations
Audit every dependency and reused codebase before integration. Firestorm, OpenSimulator and other third-party components may impose license obligations. A proprietary license cannot override those obligations or mandatory interoperability rights.

## Repository security warning
This GitHub repository was **public** when this plan was written. Do not commit proprietary implementation source, credentials or unpublished proprietary EULA material to a public repository. Move development to a private repository or change visibility with owner approval before source development. Publishing source once cannot reliably be undone by later making the repo private.

## Open decisions
Legal entity/rightsholder; EULA jurisdiction and consumer/commercial distinctions; allowed binary redistribution; trademark policy; SDK license; contribution agreement; atlas terms; privacy notice. Obtain qualified German/EU legal review before release.
