# Contributing to OpenGenesisLINK Generation 2

This repository currently hosts **public project planning and architecture documentation**, not the proprietary Gen2 server implementation.

## Suitable contributions
- Open an issue about a spec inconsistency, security concern (without exploit details), test scenario or architecture trade-off.
- Propose targeted documentation edits in a pull request.
- Clearly distinguish verified behavior, a prototype and a proposed feature.
- Explain interoperability assumptions and include testable acceptance criteria.

## Not accepted into this public repository
- OpenSimulator/Generation 1 code copied without an explicit provenance and licensing review.
- Unlicensed third-party code, proprietary assets, credentials, production configuration or personal data.
- Gen2 native server source until its publication scope and contributor terms are explicitly agreed.

## Change checklist
Check relative Markdown links, update cross-references, keep documentation in sync with `ROADMAP.md`, and make unresolved decisions visible rather than claiming implementation.

External source-code contributions to future private repositories require separate written contributor/IP terms. This file does not constitute an assignment or contribution license.
