# Security policy

## Scope
OpenGenesisLINK Generation 2 is in the architecture stage. No publicly distributed, supported Gen2 server binaries or endpoints are represented by this repository.

## Vulnerability reporting
Do not publish credentials, exploit steps, user records or private endpoints in public issues. Prefer GitHub's **private vulnerability reporting** feature for this repository **if enabled**. If that option is unavailable, request a private contact path from the maintainers without disclosing the sensitive details publicly.

## Design requirements
Threat-model the Atlas registry, cross-grid travel, signed capability tokens, parser/gateway boundary, asset permissions and sandboxed scripts before implementation. Logs must avoid credentials and sensitive player information.

No response-time or security-support SLA has been established.
